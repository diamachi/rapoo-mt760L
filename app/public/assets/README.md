# MT760L product image

The original cached product photo mt760l.webp is restored at the user's request in version 0.2.0. It is served locally in the header and interactive map; there are no runtime image downloads.

Source page: https://www.rapoo-eu.com/product/mt760l/
Source asset: https://www.rapoo-eu.com/wp-content/uploads/2024/05/MT760L_01.png--e1746094024550.webp

## App icon

`app-icon.svg` is original MIT-licensed project artwork: a simplified ergonomic mouse in the app’s slate, blue and lilac palette. It is distinct from the separately attributed product photo. `scripts/build-icons.mjs` renders it using existing macOS tools into the Mac ICNS, Windows ICO and 1024px PNG in `packaging/assets/`. No image service, package installation or external artwork is required.

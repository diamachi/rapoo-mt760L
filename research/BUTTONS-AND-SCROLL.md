# Button assignments and scrolling

2026-10-30: user confirms the original DPI writes work over the 2.4 GHz receiver.

## Reproducible resource extraction

Run with the portable runtime, from the project root:

```sh
_toolchain/portable-node-macos-arm64/node scripts/extract-profile-candidates.mjs
_toolchain/portable-node-macos-arm64/node scripts/inspect-disassembly.mjs 6feb0e40 6feb1f00
```

The extractor scans zlib/qCompress streams in the supplied executable without executing it. It writes generated JSON/QML candidates under `research/generated/profile-candidates/`. These vendor resources remain ignored research material, not distributed app source.

- Executable compressed stream offset **0x11349761**: MT760 device profile, including 11 input IDs and names.
- Stream **0x11346913**: key-code catalog. Mouse codes F0–F4, standard keyboard HID usages, consumer usages, DPI actions type 50 (codes 03–06), DIY type 52/code 00, disable type 0.
- Stream **0x11355084**: alternate MT760 profile uses DIY ID 11 instead of 3. The app uses the 0–10 layout matching the address range queried in the supplied mouse capture. If this mouse's DIY button does not respond, capture its specific profile/readback before adding ID 11.
- Streams **0x3e4ab8**, **0x403cd3**, **0x404618**: vendor scroll-line UI calls host parameter-manager settings. The executable includes macOS `com.apple.scrollwheel.scaling` commands and Windows `SystemParametersInfoW`. These are host settings, not proof of an MT760 firmware line-count register.

## Input IDs

Address = **0x0600 + 4 × ID**, established by DLL VA **0x6feb0fd6–0x6feb0fe5**.

| ID | Address | Profile input |
|---|---|---|
| 0 | 0600 | Left click |
| 1 | 0604 | Middle click |
| 2 | 0608 | Right click |
| 3 | 060c | DIY |
| 4 | 0610 | DPI |
| 5 | 0614 | Side forward |
| 6 | 0618 | Side back |
| 7 | 061c | Thumb wheel left |
| 8 | 0620 | Thumb wheel right |
| 9 | 0624 | Main wheel up |
| 10 | 0628 | Main wheel down |

Profile keywords are Chinese for left/middle/right, right-side/left-side, and wheel directions; the UI uses English equivalents. These are static profile mappings, not a new live button-detection test.

## Four-byte record encodings

The full packet is `ba a5 a5 04 [address LE32] [record] [20 zero bytes]`. In DLL object memory, parameter data starts at 0xa1. Full USB packet parameter offset is 8.

| Action | Four bytes | DLL landmark |
|---|---|---|
| Disable | 07 00 00 00 | 6feb0fef |
| Keyboard key | 01 00 usage 00 | 6feb1180–6feb122a |
| Shortcut | 02 00 modifier-mask usage | 6feb1955–6feb1b28 |
| Mouse click | 03 00 bitmask 00 | 6feb1370–6feb1497 |
| Consumer/media | 04 00 usage-high usage-low | 6feb1260–6feb12e3 |
| DPI cycle/step | 08 00 code 00 | 6feb1b65–6feb1be6 |
| Double left click | 03 00 01 01 | special case 6feb1cf4–6feb1cf8 |
| DIY / report-rate cycle | 0a 00 00 00 | 6feb1d83, catalog DIY note |
| Vertical scroll | 0b 00 direction 00 | 6feb1530–6feb15c5; 1 up, 2 down |
| Horizontal scroll | 0c 00 direction ff | 6feb1650–6feb16df; 1 left, 2 right |

Mouse bitmask follows vendor F0–F4 mapping: left 01, right 02, middle 04, back 08, forward 10. Keyboard modifiers follow USB HID: left Control bit0, Shift bit1, Alt bit2, GUI/Command bit3. The current UI supports one standard key plus any combination of those modifiers. It does not implement macros or multi-key sequences.

**Capture cross-check:** frame 106 at 0x0610 is `08 00 03 00`, exactly the DPI-button cycle-up encoder output. Frame 104 is `09 00 01 00`, a sniper action according to type-51 code-01 catalog entries; that unconfigured feature is not offered in the editor. Its exact captured replay remains allowed.

All 11 default packet layouts and supported action families are tested. This confirms generated bytes against static evidence; physical effects of newly exposed actions remain to be tested.

## Scroll helper scope and precision

`app/native/macos-scroll.mjs` binds system IOKit/CoreGraphics/CoreFoundation through the existing portable Node FFI. IOHIDManager matches mouse usage 01:02 and its input-value filter selects only wheel usage 01:38. Each raw integer wheel count is multiplied by the chosen line count and posted as a line-based scroll event. The current global natural-scroll preference determines direction at startup. Generated events carry a unique source-user-data marker to pass through the helper's session event tap. That tap removes the original accelerated vertical component of discrete scroll events, preserving horizontal axes and passing continuous/trackpad events unchanged. It does not tap keyboard events. Point-consuming apps get a 10-point-per-line representation, not a guarantee of their rendered line height.

This uses **raw HID increments**, not accelerated/coalesced OS delta magnitudes. For this MT760L descriptor's conventional wheel, increments correspond to wheel steps; accumulated counts are preserved. All HID mouse wheels are affected while running; this is not a receiver-specific firmware setting. Other high-resolution wheels may use multiple raw increments per notch, and apps that scroll in pixels interpret visual distance themselves. These limitations are explicitly shown in the UI. Physical behavior of the live helper still needs testing; native field conversion and native symbol binding have been checked without posting events or installing an event tap.

The helper never starts automatically. Start/Stop require the same local session token and Origin protection as device writes. Stop/server close terminates it, and it checks its parent process while running so it exits even after unexpected server termination. No system preferences, login items, driver installations or global tools are changed.

Native validation command (creates only an isolated, unposted event; no event tap):

```sh
_toolchain/portable-node-macos-arm64/node --experimental-ffi app/native/macos-scroll.mjs --self-test
```

Real scroll interception may require macOS Accessibility and Input Monitoring permission for Terminal/portable Node. Those permissions are left to the user. Physical scroll behavior has not been tested by the agent.

# Project working preferences

- Keep changes and preview builds local while the owner tests them. Do not create, publish, replace or update a GitHub release until the owner has completed testing and explicitly approved that release.
- Do not install tools globally on this Mac. Use the labeled portable runtimes in `_toolchain/` and already available system tools. Keep generated build caches inside this workspace.
- Never upload `personal/` or its handbook to GitHub or include it in distribution archives.
- Preserve original vendor software, captures and research evidence. Distinguish report transmission from measured hardware behavior; do not call a setting verified merely because a write returned successfully.
